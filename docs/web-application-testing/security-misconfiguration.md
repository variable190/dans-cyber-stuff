# Security Misconfiguration

## What is Security Misconfiguration?

Security Misconfiguration occurs when security settings are defined insecurely or left at default values.

## Exploits

- [Default Credentials](security-misconfiguration/default-credentials.md)
- [Verbose Errors](security-misconfiguration/verbose-errors.md)
- [Headers and Cloud Configs](security-misconfiguration/headers-cloud.md)

## Impact

Unauthorized access, disclosure.

## Prevention

Harden, remove defaults, apply headers.

## Tools & Payloads

Nikto, scanners.
