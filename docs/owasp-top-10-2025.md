# OWASP Top 10 2025

## A01:2025 - Broken Access Control
Applications fail to properly restrict what authenticated users are allowed to do or access.

**Relevant pages:**
- [Broken Access Control](web-application-testing/broken-access-control.md)
- [Business Logic Vulnerabilities](web-application-testing/business-logic-vulnerabilities.md)
- [Path Traversal](web-application-testing/path-traversal.md)
- [SSRF](web-application-testing/ssrf.md)

## A02:2025 - Security Misconfiguration
Security settings are incorrectly configured or left at insecure defaults.

**Relevant pages:**
- [Security Misconfiguration](web-application-testing/security-misconfiguration.md)

## A03:2025 - Software Supply Chain Failures
Vulnerabilities are introduced through third-party components or compromised build and deployment processes.

**Relevant pages:**
- [Reconnaissance](reconnaissance.md)

## A04:2025 - Cryptographic Failures
Sensitive data is not adequately protected due to weak encryption or key management.

## A05:2025 - Injection
User input is not properly validated or sanitised before being processed by an interpreter.

**Relevant pages:**
- [SQL Injection](web-application-testing/sql-injection.md)
- [Command Injection](web-application-testing/command-injection.md)
- [NoSQL Injection](web-application-testing/nosql-injection.md)
- [XXE](web-application-testing/xxe.md)
- [File Inclusion](web-application-testing/file-inclusion.md)

## A06:2025 - Insecure Design
Fundamental flaws in the application's design and business logic cannot be fixed by secure implementation alone.

**Relevant pages:**
- [Business Logic Vulnerabilities](web-application-testing/business-logic-vulnerabilities.md)

## A07:2025 - Authentication Failures
Weak authentication and session management allow user accounts to be compromised.

**Relevant pages:**
- [Broken Authentication](web-application-testing/broken-authentication.md)

## A08:2025 - Software or Data Integrity Failures
Critical software and data lack proper integrity verification.

**Relevant pages:**
- [Insecure Deserialisation](web-application-testing/insecure-deserialisation.md)
- [XXE](web-application-testing/xxe.md)
- [File Upload Attacks](web-application-testing/file-upload-attacks.md)

## A09:2025 - Security Logging and Alerting Failures
Security-relevant events are not adequately logged, monitored or alerted on.

## A10:2025 - Mishandling of Exceptional Conditions
Errors and exceptional conditions are handled in ways that create vulnerabilities or leak information.

**Relevant pages:**
- [Security Misconfiguration](web-application-testing/security-misconfiguration.md)
